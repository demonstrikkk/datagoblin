# 18 — DESIGN SYSTEM (Fieldwork: editorial research instrument)

Visual direction: quiet, editorial, investigative data workspace (Bloomberg-meets-editorial). Dataset is hero; evidence one click away. NOT: generic AI dashboard, purple gradients, glassmorphism, neon, excessive cards, floating AI orb, chat-everywhere, giant gradient hero, Inter-everywhere.

Typography: Display Instrument Serif / Newsreader; UI DM Sans / Geist / IBM Plex Sans (verify availability at build; fallback system serif/sans, never block on fonts).

Palette: Ink #161615, Paper #F5F2EA, Warm white #FBFAF6, Muted #74736D, Rule #D9D4C8, Accent #A77A32. Tokens in design/design-tokens.json.

Principles: editorial hierarchy; sparse borders; dense-but-readable data; strong typography; few cards; no decorative AI imagery; motion explains state; evidence feels inspectable. Proof Inspector is the visual identity.
